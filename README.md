# Smooth Keyboard Mouse Control { X11, xdotools }
Terminal command-line application for smooth keyboard mouse control using X11 library and xdotools. (There will be no double-click without a mouse :3)

## Requirements 
1. xorg graphical server (if you're using another graphical server I don't recommend using this project.)
2. xdotools `sudo apt install xdotool` (debian) or the proper package manager syntax of your distro.
3. this project uses gcc/g++, so probably you don't need to install anything.

## Installation
This project is a small project, you should always build this project from source.
1. Download the project and extract it to desired folder.
2. Read build.sh and run the script `bash build.sh`.
3. Read example.sh and run the script `bash example.sh` to start a bash script example using numpad keys remap.

## Usage 
1. `<application-path> --help` display usage help.

Tested on Debian. As there are many distros for linux, I will appreciate feedback from other users.
